API Rapid Market

Selecciona un endpoint para abrir la interfaz navegable y consultar o enviar solicitudes.

Autenticación

  • POST /api/login/ — iniciar sesión y obtener tokens.
  • POST /api/login/refresh/ — renovar el token de acceso.
  • POST /api/logout/ — cerrar sesión.

Datos

  • GET /api/dashboard/ — resumen.
  • GET /api/references/ — catálogos.
  • POST /api/providers/ — registrar proveedor (Administrador).
  • GET, POST /api/products/ — consultar o crear productos.
  • GET, PATCH, DELETE /api/products/<product_id>/ — consultar, modificar o desactivar un producto.
  • GET, POST /api/sales/ — consultar o registrar ventas.
  • GET, POST /api/purchases/ — consultar o registrar compras (Administrador).
  • POST /api/purchases/<purchase_id>/<action>/ — ejecutar una acción de compra (Administrador).
  • GET, POST /api/expenses/ — consultar o registrar gastos (Administrador).

Las rutas protegidas requieren un token de acceso. La interfaz permite probar los métodos y enviar JSON; para endpoints protegidos, envía Authorization: Bearer <access> con un cliente HTTP que permita configurar cabeceras, como Postman.
